# Blogstore Server Agent Guide

Backend server for the Blogstore project, built with [Serverpod](https://serverpod.dev).

- [Workflow & MCP Guide](file:///C:/Users/manis/Desktop/workspace/blogstore_server/docs/workflow.md)

## Responsibilities
- Manage data models (`.spy.yaml`).
- Implement RPC endpoints in `lib/src/endpoints`.
- Configure authentication and permissions in `lib/server.dart`.
- Handle database migrations and repairs.
